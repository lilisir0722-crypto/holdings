# 持仓判断工具

日期：2026-08-16

## 背景

使用者在国金证券已有账户，同时买股票、基金、ETF。现在容易瞎买，也不靠指标做决定。需要一个本地工具：说清楚「我现在买的这些怎样」，并给出带依据的判断。行情用开源库 easy-tdx。国金没有持仓导出，代码、数量、成本由使用者手填。

## 目标

打开本地网页，看到每只的现价、相对成本、是否过重、近期公告，以及用白话写的判断。每条判断下面列出依据（用了哪些数字、数字从哪来）。

## 非目标（第一版不做）

- 登录国金或任何券商
- 自动下单
- 教指标（MACD、KDJ 等不出现在界面上）
- 单独「看一只」页、大盘环境页（后补）
- 自造词汇（不用「三桶」「核心」「卫星」「体检」等产品黑话）

## 用语

只用常见词：股票、基金、代码、数量、成本、现价、涨跌、公告、判断、依据。ETF 按股票方式填代码、走行情。场外基金选「基金」；查不到行情就如实说没有行情。

## 用法

1. 添加一行：类型（股票 / 基金）、代码、数量、成本。名称能查到就自动填。
2. 点刷新：用 easy-tdx 更新现价、近 120 个交易日最高最低、近 7 天公告。
3. 阅读判断。每条判断必须带依据。可以有偏买或偏卖的结论，但不能只有一句「立即买入/卖出」、没有论证。

## 结构

- `store`：本地 `data/holdings.json`，增删改查持仓
- `market`：easy-tdx 取报价、K 线、公告；失败时保留上次缓存并标明过期
- `judge`：纯函数，只吃持仓 + 行情，输出判断和依据
- `web`：一页，本机 FastAPI

## 判断规则（第一版写死）

对每一只：

- 没有现价：判断「暂时没有行情，无法判断现在贵不贵」。依据：查询失败或该代码在行情源中不存在。
- 该只市值 / 全部有行情的市值 > 30%：判断「这只在你现在这些里面占比偏高」。依据：市值和占比。
- （现价 - 成本）/ 成本 < -20%：判断「相对你的成本亏得比较多」。依据：成本、现价、幅度。
- （现价 - 成本）/ 成本 > 50%：判断「相对成本赚得比较多」。依据同上。
- 现价处于近 120 个交易日最高价的 10% 以内：判断「价格靠近这段时间的高位」。依据：现价、120 日最高、最低。
- 现价处于近 120 个交易日最低价的 10% 以内：判断「价格靠近这段时间的低位」。依据同上。
- 近 7 天有公告：判断「最近有公告，先读完再决定加不加」。依据：公告标题和日期。

对全部：

- 能算出总市值和相对成本的总盈亏，用一句话概括，并列出数字依据。
- 没有任何触发项时：判断「没有特别需要立刻处理的情况」，依据为总盈亏幅度和最大一只占比。

同一只可以有多条判断。

## 行情

- 股票 / 场内 ETF：easy-tdx，市场按代码推断（6/5/9 开头上海，0/1/2/3 开头深圳）。
- 场外基金：先试 easy-tdx；失败则标记没有行情，仍保留手填的数量和成本。
- 本机无外网或行情服务器超时：页面写明连不上，展示上次成功数据的时间。

## 数据

`data/holdings.json` 不提交到 git。每条：`id, kind, code, name, quantity, cost, updated_at`，以及可选的行情缓存。

## 运行

Python ≥ 3.10。`uv sync` 后 `uv run holdings` 打开本机网页。
