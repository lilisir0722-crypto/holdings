# 技术弹层：规则趋势 + DeepSeek 说明

日期：2026-08-16

## 目标

在持仓技术弹层中：

1. **规则趋势**：用日 K 给出短线偏强/偏弱/震荡 + 数字依据。
2. **可选模型说明**：若环境变量有 DeepSeek Key，把趋势、指标信号、成本盈亏、现金交给模型，生成白话说明。
3. 无 Key 或调用失败时，规则部分照常，不阻塞弹层。

## 非目标

- 预测「后面一定亏/赚」
- 只有「立即买入/卖出」、没有论证
- 登录券商
- 把降集中度当用户目标（用户更关心盈亏）

## DeepSeek 配置（环境变量）

- `DEEPSEEK_API_KEY`：必填才调用
- `DEEPSEEK_BASE_URL`：可选，默认 `https://api.deepseek.com`
- `DEEPSEEK_MODEL`：可选，默认 `deepseek-chat`

兼容 OpenAI Chat Completions 协议。

## 规则趋势（写死）

用日 K 收盘价：

- 近 20 日涨跌幅
- 现价相对 MA20（上/下）
- MA5 与 MA20 关系（多头/空头/纠缠）

汇总成一句：`短线偏强` / `短线偏弱` / `短线震荡`，并列出依据。

## 模型提示约束

只根据传入 JSON/要点回答；不编造行情；可以偏买或偏卖，但必须先写论证再下判断；用白话；侧重相对成本盈亏与「现在怎样」。

## 弹层顺序

总倾向 → 走势（规则）→ 说明（模型，可选）→ 有信号 → 其余

## 验收

1. 无 Key：有走势，无模型段或注明未接。
2. 有 Key：有说明段落；失败时降级。
3. 测试不依赖外网（趋势纯函数；模型调用可 mock）。
