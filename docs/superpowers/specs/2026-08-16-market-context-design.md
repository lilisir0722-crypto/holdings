# 技术页：资金 / 板块 / 量价信号

日期：2026-08-16

## 背景

技术分析已用 easy-tdx 日 K 算约 34 个指标，并有走势规则与可选 DeepSeek 说明；原先以持仓页弹层展示。README 里还有资金流向、所属板块等未接入；多数量价类指标只堆数字、没有「有信号」白话。

使用者选择按 **A→B→C** 顺序搬进同一技术页：资金 → 板块 → 更多量价信号；并改为**整页**查看，不再用弹层。

## 目标

点已持仓名称进入技术页（`GET /tech/{code}`），页内增加三块有依据的信息：

1. **资金**：个股/ETF 资金流向（主力、散户方向，能取到的字段）。
2. **板块**：所属板块（少量）+ 板块汇总（成交、主力净流入及近 3/5 日若有）。
3. **量价信号**：对 OBV、MFI、DMI、VR 增加常用阈值判断；触发则进「有信号」，否则仍在「其余」。

失败时只空对应块，不影响已有总倾向、走势、指标列表。

## 非目标

- 缠论、回测、策略库、Web UI 当实盘下单。
- 全市场异动榜原样当「这只一定异动」（只对当前代码过滤后展示）。
- 资金/板块拆成与技术分析无关的另一套入口。
- 「立即买入 / 立即卖出」当全文、不附依据。
- 登录券商或自动下单。
- 用资金/板块单独改写买卖结论（资金/板块只进依据，结论仍要连上指标和成本）。
- 继续使用弹层 / `fetch` 塞进遮罩。

## 交互与展示顺序

持仓页：名称链到 `/tech/{code}`（本页跳转；页顶「返回持仓」回 `/`）。去掉 modal 相关 DOM/JS。

技术页自上而下：

1. 返回持仓 + 名称、代码、现价  
2. 总倾向 + 依据（现有；可附带资金/板块一句摘要进依据，见下）  
3. 走势 + 说明（模型，可选）  
4. **资金**（新）  
5. **板块**（新）  
6. **异动**（全市场名单过滤到当前代码）  
7. **缠论**（easy_tdx `to_dict`：分型/笔/中枢/线段/买卖点/背驰，全部列出）  
8. 有信号  
9. 其余  

加载：浏览器直接打开 `GET /tech/{code}`（整页 HTML，可复用现有 `tech.html` 包进站点壳）；服务端在算指标的同次连接里尽量拉资金与板块。任一块超时或空，该块写明原因，其余照常。加载中由浏览器原生等待即可（可选页内「在算」文案）。

## 数据来源（easy-tdx MacClient）

| 块 | API | 用法 |
|----|-----|------|
| A 资金 | `get_capital_flow(market, code)` | 取近期行；展示主力净流入、散户相关字段（以实际列名为准，白话标注）。无表或空 → 「这只暂时没有资金流向」。 |
| B 板块 | `get_belong_board` → 选 1～2 个主要所属（优先行业 HY，其次概念 GN；名称+代码） | 对每个选中板块 `get_board_summary(board_symbol)`：成分股数、成交额、主力净流入、近 3/5 日主力净流入（有则写）。对不上或失败 → 「板块对不上 / 暂无」。 |
| C 量价 | 已有日 K + `compute_indicators` | 规则引擎扩展，不另拉接口。 |

场外基金无日 K：资金/板块若也不可用，与现逻辑一致写明算不了；不强行伪造。

## 量价信号规则（C，写死可后续加）

- **OBV**：近若干日（如 5 日）与收盘同向/背离的粗判；明显背离记有信号。  
- **MFI**：常用 0–100；约 >80 偏热、约 <20 偏冷 → 有信号。  
- **DMI**：PDI/MDI 交叉或 ADX 处于偏高且方向明确 → 有信号。  
- **VR**：相对常用冷热区（实现时用库内数值与常见阈值对齐）→ 有信号。  

解读用白话：偏强、偏弱、量价是否跟上；附关键数字作依据。不展开公式课。

## 总倾向如何用 A/B

- 总倾向主逻辑仍：技术多空信号汇总 + 相对成本盈亏 + 手头现金（现有）。  
- A/B **不单独**当成买卖结论；资金/板块只进依据，和指标、成本一起论证。  
- 可选：若资金或板块有明确一句摘要，追加进 `stance_evidence`（例如「近几日主力净流入为负」），方便和说明（模型）共用依据。

## 实现分层

- `market`：封装 `fetch_capital_flow`、`fetch_belong_boards` / `fetch_board_summary`（或一次 `fetch_market_context(code)`），与现有 `open_mac_client` 复用连接。  
- `tech`：扩展 OBV/MFI/DMI/VR 的 handler；报告结构增加 `capital`、`boards`（或等价字段）供模板渲染。  
- `web` / `tech.html`：整页模板（含返回持仓）；按顺序渲染资金、板块两节；`index.html` 去掉弹层。  
- 测试：A/B 用假 DataFrame/dict；C 用固定序列；不依赖外网通达信。

## 用语

股票、基金、代码、现价、判断、依据、资金、板块、主力净流入。不造产品黑话。

## 验收

1. 点已持仓名称：进入独立技术页（非弹层）；走势下可见「资金」「板块」两节（有数据或明确「暂无」）；可返回持仓。  
2. OBV/MFI/DMI/VR 在触发阈值时出现在「有信号」，并有白话 + 数字依据。  
3. 资金或板块接口失败时，指标与走势仍正常。  
4. 总倾向和说明都要带依据；可以有偏买/偏卖判断，不能只有一句买卖、没有论证。总倾向不以资金/板块单独翻盘。  
5. 相关单测通过。

## 说明：异动 / 缠论

- **异动**：`get_unusual` 是全市场名单，页上只留下当前代码；对不上写「今天没出现在异动名单」。
- **缠论**：用 `ChanlunAnalyser.process_klines` / `to_dict()` 列出分型、笔、中枢、线段、买卖点、背驰。买卖点连同库给的说明一并展示，当作带论证的结论，不因「怕像口令」而删掉。总倾向规则不单靠买卖点改写。
