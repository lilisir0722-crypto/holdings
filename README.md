# 持仓

本地小工具。你手填股票或基金的代码、数量、成本。点刷新后，用 [easy-tdx](https://github.com/handsomejustin/easy_tdx) 拉现价和公告，用白话写出判断，每条判断下面列出依据。

不登录券商。不下单。不把指标丢到页面上。

## 运行

需要 Python 3.10+ 和 [uv](https://docs.astral.sh/uv/)。

```bash
cd holdings
uv sync
uv run holdings
```

浏览器会打开 `http://127.0.0.1:8765`。数据存在当前目录 `data/holdings.json`，不会提交到 git。

## 用法

1. 类型选股票或基金，填代码、数量、成本。名称可空，刷新后会尽量补上。
2. 点「刷新行情」。第一次选服务器可能要几十秒。
3. 读上面的判断和依据。场外基金可能没有行情，页面会写明。

ETF 按股票填 6 位代码即可（例如 `510300`）。

## 判断在说什么

- 没有现价：无法判断贵不贵
- 某一只市值超过全部的 30%（至少两只时）：这只占比偏高
- 相对成本亏超过 20%，或赚超过 50%
- 现价靠近近 120 个交易日的高位或低位
- 近 7 天有公告：先读完再决定加不加

依据里会写用到的数字。这不是投资建议，也不能替你下单。
